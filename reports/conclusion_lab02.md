# Conclusión

El desarrollo del LAB02 permitió completar un proceso reproducible de búsqueda, selección y auditoría de un dataset público para un problema de clasificación. El conjunto de datos seleccionado fue **Statlog (German Credit Data)**, disponible en el UCI Machine Learning Repository. El dataset contiene 1,000 registros, 20 variables predictoras y una variable objetivo binaria denominada `class`, con las clases `1 = Good` y `2 = Bad`. La auditoría realizada confirmó que el conjunto de datos no presenta valores faltantes y que las variables corresponden a información disponible antes de la decisión crediticia.

La variable `class` fue definida como target y no fue necesario eliminar variables predictoras por razones de fuga de información. La partición de los datos se realizó utilizando un 80 % para entrenamiento y un 20 % para prueba, con `random_state=42` y estratificación de las clases. El preprocesamiento se incorporó dentro de un `Pipeline`, utilizando imputación y escalamiento para las variables numéricas, e imputación y codificación one-hot para las variables categóricas.

Como línea base se utilizó un `DummyClassifier` con estrategia de clase más frecuente, que obtuvo un **F1 macro de 0.4118**. Posteriormente se implementó un clasificador **SVM con kernel RBF**, utilizando `C=1` y `gamma="scale"`, de acuerdo con la configuración establecida en el laboratorio. Este modelo obtuvo un **F1 macro de 0.7200** sobre el conjunto de prueba. El resultado muestra una diferencia considerable respecto a la línea base y evidencia que el modelo utiliza información de las variables predictoras para realizar la clasificación.

También se realizó una búsqueda exploratoria de hiperparámetros mediante `GridSearchCV`, evaluando diferentes combinaciones de `C` y `gamma` mediante validación cruzada estratificada de cinco particiones. La mejor combinación según el F1 macro de validación cruzada fue `C=10` y `gamma=0.1`, con un F1 macro de aproximadamente **0.6688**. Al evaluar esta configuración sobre el conjunto de prueba se obtuvo un **F1 macro de 0.6855**, inferior al resultado del SVM base. Por esta razón, el ajuste exploratorio no se presenta como una mejora del modelo final.

El análisis permitió comprobar la importancia de separar correctamente la auditoría de datos, el preprocesamiento, el entrenamiento y la evaluación. También mostró que una configuración con mejores resultados en validación cruzada no necesariamente obtiene un mejor resultado en un conjunto de prueba independiente. Finalmente, el ejercicio deja una base reproducible para futuras evaluaciones, incorporando nuevos modelos, análisis de variables y estrategias de validación sin modificar el contrato de datos establecido.
