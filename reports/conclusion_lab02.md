## Conclusión

El desarrollo de este ejercicio permitió integrar la selección y auditoría de un dataset público con la implementación de un modelo de clasificación SVM reproducible. El dataset seleccionado fue **Predict Students' Dropout and Academic Success**, disponible en el UCI Machine Learning Repository, compuesto por 4,424 registros, 36 variables predictoras y una variable objetivo con tres categorías: Dropout, Enrolled y Graduate. Durante la auditoría se verificó la estructura del conjunto de datos, la distribución de las clases, la ausencia de valores faltantes y la procedencia de la información. También se identificó la necesidad de considerar la dimensión temporal de algunas variables académicas, debido a que varias corresponden al desempeño registrado durante el primer y segundo semestre.

Como línea base se implementó un clasificador SVM con kernel RBF, estandarización de las variables y la configuración `C=1` y `gamma="scale"`. El modelo base obtuvo un F1 macro de 0.6785, superando ampliamente el clasificador Dummy utilizado como referencia, cuyo F1 macro fue de 0.2221. Esto demuestra que el modelo SVM logró identificar patrones relevantes para diferenciar las tres categorías del conjunto de datos.

Como adaptación técnica se realizó una comparación controlada de nueve combinaciones de los hiperparámetros `C` y `gamma`, manteniendo constante el dataset, la partición 80/20, el estado aleatorio y el procedimiento de preprocesamiento. La configuración que obtuvo el mayor F1 macro dentro de las combinaciones evaluadas fue `C=1` y `gamma=0.01`, con un resultado de 0.6876. Esto representa una mejora de 0.0091 puntos de F1 macro respecto al escenario base, equivalente aproximadamente a 0.91 puntos porcentuales.

El análisis por clase mostró diferencias importantes. La categoría Graduate alcanzó un F1-score de 0.85 y un recall de 0.94, mientras que Dropout obtuvo un F1-score de 0.77. La categoría Enrolled presentó el desempeño más bajo, con un F1-score de 0.44 y un recall de 0.38. Por tanto, aunque la adaptación produjo una mejora global moderada, persisten dificultades para identificar correctamente algunos casos de estudiantes Enrolled.

Finalmente, el ejercicio permitió comprobar la importancia de mantener un procedimiento reproducible y de evaluar las modificaciones mediante métricas comparables. La experiencia también evidencia que una mejora en una métrica global no implica necesariamente un comportamiento uniforme entre todas las clases. Los resultados obtenidos constituyen una base para futuras mejoras del modelo, incluyendo otras estrategias de selección de hiperparámetros, análisis de variables y técnicas de reducción dimensional.
